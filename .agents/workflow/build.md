# Build Workflow

1. Choose the smallest safe design that fits existing boundaries.
2. Update the contract or specification before or alongside implementation when behavior changes.
3. Implement in narrow increments; keep each increment runnable.
4. Add tests at the level that proves the changed behavior.
5. Run relevant formatting, static analysis, and tests; investigate failures.
6. Record a durable decision in an ADR only when warranted.

Pause for approval before irreversible migrations, broad rewrites, production operations, or scope expansion.
