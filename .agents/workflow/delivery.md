# Delivery Workflow

Finish with a concise handoff:

1. Outcome and key files changed.
2. Validation actually run and its result.
3. Important assumptions, risks, or intentionally deferred work.
4. Any action the user must take, such as secrets, migration, deploy, or approval.

Update session memory before stopping if work is incomplete or a future agent needs context. Promote only durable facts to long-term memory. Keep handoffs factual; link to project docs rather than repeating large details.
