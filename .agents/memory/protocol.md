# Memory Protocol

At session start: read `short_term_memory.md`, `long_term_memory.md`, relevant `docs/`, and current repository state. Treat contradictions as a prompt to verify, not to guess.

During work: update short-term memory with the live goal, change areas, validation, blockers, and next action. At a milestone: add confirmed decisions, invariants, or stable facts to long-term memory.

At handoff: mark completed tasks, record remaining work, and remove stale scratch notes. Preserve long-term decision history by adding a dated superseding entry rather than editing history away. Follow `memory/rules.md`.
