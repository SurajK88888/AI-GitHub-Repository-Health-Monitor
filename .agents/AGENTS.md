# Agent Entry Point

Use this playbook with any AI agent or developer.

Before changing code: read `.agents/workflow/intake.md`, the relevant `.agents/project` docs, and local repository instructions.

Work in small, reviewable changes. Prefer evidence over assumptions. Do not expose secrets, alter unrelated files, or claim tests passed unless they ran.

Use:
- `.agents/architecture/` for system boundaries and decisions.
- `.agents/rules/` for implementation constraints.
- `.agents/testing/` for validation.
- `.agents/memory/` for brief, factual continuity; read `.agents/memory/rules.md` and use the long- and short-term files.
- `.agents/templates/` to create project documents.

Local repository instructions and user requests take priority over this playbook.
