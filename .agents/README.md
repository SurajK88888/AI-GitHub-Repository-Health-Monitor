# Shared AI Agent Playbook

This folder is portable guidance, not project memory. Copy it to each repository root as `.agents/` and point your agent platform to `AGENTS.md`.

Read in this order:
1. `.agents/AGENTS.md`
2. `.agents/workflow/intake.md`
3. Relevant rules, architecture, testing, and templates

Keep project facts in the repository's `.agents/docs/` folder, never here. Update this playbook only when a rule proves useful across multiple projects.

Every file is intentionally small: under 1,600 characters.
