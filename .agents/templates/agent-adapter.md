# Platform Adapter Template

Place this content in the platform's required instruction file, adapting only its syntax.

```text
Read and follow .agents/AGENTS.md before working.
Also read relevant repository instructions and docs/ pages.
User and repository instructions take priority.
Keep changes scoped, validate them, and report actual verification.
```

Do not paste project secrets, lengthy documentation, or generated memory into the adapter. The adapter should remain a short entry point to the canonical playbook.
