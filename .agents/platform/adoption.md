# New Project Adoption

1. Copy `.agents/` to the new repository root.
2. Create `docs/` using the structure in `project/where-docs-go.md`.
3. Copy `templates/project-brief.md` to `docs/product/brief.md` and complete it.
4. Create project-local `.agents/memory/long_term_memory.md` and `short_term_memory.md` from templates if continuity is useful.
5. Add a platform-specific pointer to `.agents/AGENTS.md`.
6. Tailor only rules that genuinely differ for this repository; document exceptions.

Review shared guidance quarterly or after repeated friction. Keep it generic, concise, and evidence-based.
