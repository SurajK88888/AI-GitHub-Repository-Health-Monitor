# Platform Compatibility

This folder uses plain Markdown so it works with most AI tools. Each platform may need a small pointer file or configuration that tells it to read `.agents/AGENTS.md`.

Do not duplicate all rules into platform-specific files. Keep this folder canonical and make adapters brief. If a platform has a higher-priority instruction format, create a pointer that preserves its required syntax and links back here.

Platform behavior, tool permissions, and local repository instructions may differ. Follow the stricter applicable safety constraint.
